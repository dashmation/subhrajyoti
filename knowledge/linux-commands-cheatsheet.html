1. File Operations

File operations are the most basic Linux skill — creating, copying, moving, and inspecting files you work with daily.

CommandDescriptionExample
lsList directory contents
▶ Show
ls           # list files
ls -la       # long format + hidden
ls -lh       # human-readable sizes
ls -ltr      # sort by time (oldest first)
ls *.txt     # list only .txt files
cpCopy files/directories
▶ Show
cp file.txt backup.txt       # copy file
cp -r dir1/ dir2/            # copy directory recursively
cp -p file.txt dest/         # preserve permissions
cp -i file.txt dest/         # prompt before overwrite
mvMove/rename files
▶ Show
mv old.txt new.txt           # rename
mv file.txt /tmp/            # move to directory
mv -i src dest               # prompt before overwrite
rmRemove files/directories
▶ Show
rm file.txt                  # remove file
rm -r dir/                   # remove directory recursively
rm -f file.txt               # force remove (no prompt)
rm -rf dir/                  # force remove dir (DANGEROUS)
touchCreate empty file / update timestamp
▶ Show
touch newfile.txt            # create empty file
touch -t 202401011200 f.txt # set specific timestamp
catDisplay file contents
▶ Show
cat file.txt                 # display entire file
cat -n file.txt              # with line numbers
cat f1.txt f2.txt > combined.txt # concatenate
head / tailShow beginning/end of file
▶ Show
head -20 file.txt            # first 20 lines
tail -20 file.txt            # last 20 lines
tail -f /var/log/syslog      # follow (live updates)
tail -f -n 100 app.log      # follow last 100 lines
lnCreate links
▶ Show
ln -s /path/to/file link_name  # symbolic link
ln file.txt hardlink.txt       # hard link
readlink -f link_name          # resolve symlink path
fileDetermine file type
▶ Show
file image.png               # → PNG image data
file script.sh               # → Bourne-Again shell script
statDisplay file details
▶ Show
stat file.txt                # size, permissions, timestamps
wcWord/line/byte count
▶ Show
wc file.txt                  # lines, words, bytes
wc -l file.txt               # line count only
wc -w file.txt               # word count only
diffCompare files
▶ Show
diff file1.txt file2.txt     # show differences
diff -u f1.txt f2.txt        # unified format
diff -r dir1/ dir2/          # compare directories

3. File Permissions & Ownership

Permissions control who can read, write, or execute files — critical for security and shared systems.

CommandDescriptionExample
chmodChange file permissions
▶ Show
chmod 755 script.sh          # rwxr-xr-x
chmod 644 file.txt           # rw-r--r--
chmod +x script.sh           # add execute permission
chmod -w file.txt            # remove write permission
chmod u+x,g+r file          # user+exec, group+read
chmod -R 755 dir/            # recursive
chownChange file owner
▶ Show
chown user file.txt          # change owner
chown user:group file.txt    # change owner and group
chown -R user:group dir/     # recursive
chgrpChange group ownership
▶ Show
chgrp devteam file.txt       # change group
chgrp -R devteam project/    # recursive
umaskSet default permissions
▶ Show
umask                        # show current (e.g. 022)
umask 077                    # new files: owner only
getfacl / setfaclAccess control lists
▶ Show
getfacl file.txt             # view ACLs
setfacl -m u:bob:rw file.txt # give bob read+write

4. Text Processing

Text processing tools (grep, sed, awk) are Linux superpowers — they transform and extract data from files and streams.

CommandDescriptionExample
grepSearch text patterns
▶ Show
grep "error" log.txt         # find lines with "error"
grep -i "error" log.txt      # case-insensitive
grep -r "TODO" src/          # recursive search
grep -n "func" *.py          # with line numbers
grep -c "error" log.txt      # count matches
grep -v "debug" log.txt      # invert (exclude)
grep -E "err|warn" log.txt   # extended regex (OR)
grep -l "main" *.java        # files containing match
sedStream editor (find/replace)
▶ Show
sed 's/old/new/' file.txt         # replace first per line
sed 's/old/new/g' file.txt        # replace all
sed -i 's/old/new/g' file.txt     # in-place edit
sed -n '5,10p' file.txt           # print lines 5-10
sed '/^#/d' file.txt              # delete comment lines
sed -i '3d' file.txt              # delete line 3
awkPattern processing language
▶ Show
awk '{print $1}' file.txt         # print first column
awk -F',' '{print $2}' data.csv   # CSV 2nd column
awk '/error/ {print}' log.txt     # lines matching pattern
awk '{sum+=$1} END {print sum}'   # sum first column
awk 'NR==5,NR==10' file.txt       # lines 5 to 10
sortSort lines
▶ Show
sort file.txt                # alphabetical sort
sort -n file.txt             # numeric sort
sort -r file.txt             # reverse sort
sort -k2 file.txt            # sort by 2nd column
sort -u file.txt             # sort + unique
uniqFilter duplicates
▶ Show
sort file | uniq             # remove duplicates
sort file | uniq -c          # count occurrences
sort file | uniq -d          # show only duplicates
cutExtract columns/fields
▶ Show
cut -d',' -f1,3 data.csv     # fields 1 and 3
cut -c1-10 file.txt          # first 10 characters
cut -d':' -f1 /etc/passwd    # usernames
trTranslate/delete characters
▶ Show
echo "hello" | tr 'a-z' 'A-Z'   # → HELLO
echo "hello" | tr -d 'l'         # → heo
tr -s ' ' < file.txt             # squeeze spaces
teeRead stdin, write to file + stdout
▶ Show
echo "log" | tee output.txt      # write + display
cmd | tee -a log.txt             # append to file
xargsBuild commands from stdin
▶ Show
find . -name "*.tmp" | xargs rm  # delete found files
cat urls.txt | xargs curl        # curl each URL
find . -name "*.py" | xargs grep "import"

5. Search & Find

Finding files and commands quickly saves time — use find for criteria-based search, locate for speed.

CommandDescriptionExample
findSearch files by criteria
▶ Show
find . -name "*.txt"              # by name
find . -iname "*.jpg"             # case-insensitive
find /var -size +100M             # files > 100MB
find . -mtime -7                  # modified in last 7 days
find . -type d                    # directories only
find . -type f -empty             # empty files
find . -perm 755                  # by permissions
find . -user bob                  # by owner
find . -name "*.log" -delete      # find and delete
find . -name "*.sh" -exec chmod +x {} \;
locateFast file search (indexed)
▶ Show
locate filename.txt          # fast search
sudo updatedb                # update index
whichFind command location
▶ Show
which python3                # → /usr/bin/python3
which -a java                # all locations
whereisFind binary, source, man pages
▶ Show
whereis nginx                # binary + man + source
typeDescribe a command
▶ Show
type ls                      # → ls is aliased to...
type cd                      # → cd is a shell builtin

CommandDescriptionExample

▶ Show

▶ Show
Ctrl+Z                       # suspend current process
bg                           # resume in background

command &                    # start in background

▶ Show

15. Cron & Scheduling

Scheduled tasks automate recurring work — backups, reports, cleanup, monitoring.

CommandDescriptionExample
crontabSchedule recurring tasks
▶ Show
crontab -e                   # edit cron jobs
crontab -l                   # list cron jobs
crontab -r                   # remove all jobs

# Cron format: min hour day month weekday command
# ┌───── min (0-59)
# │ ┌───── hour (0-23)
# │ │ ┌───── day (1-31)
# │ │ │ ┌───── month (1-12)
# │ │ │ │ ┌───── weekday (0-6, Sun=0)
*/5 * * * * /path/script.sh  # every 5 minutes
0 2 * * * /backup.sh         # daily at 2 AM
0 0 * * 0 /weekly.sh         # every Sunday midnight
0 9 1 * * /monthly.sh        # 1st of month at 9 AM
atSchedule one-time task
▶ Show
at 2:00 AM tomorrow          # schedule command
echo "cmd" | at now + 5 minutes
atq                          # list pending jobs
atrm 3                       # remove job #3
systemd timerModern alternative to cron
▶ Show
systemctl list-timers        # list all timers
